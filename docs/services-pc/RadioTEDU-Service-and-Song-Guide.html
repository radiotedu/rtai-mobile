Add or update songs

SystemPut approved music hereWhat happens next
VotingF:\RadioTEDU Songs\Voting\<Genre>Detected automatically in about 10 seconds. Put each file inside its correct genre folder.

  1. Confirm the music is licensed/approved for the destination.
  2. Use a clear filename and correct Artist/Title metadata. Avoid temporary downloads, shortcuts and duplicate copies.
  3. Copy the file completely, then wait for the refresh described above.
  4. Verify it appears before removing the old file.

Safest formats: MP3, FLAC, M4A, OGG, OPUS and WAV. Voting and AI also support several additional formats.

Restart one component

Open PowerShell as Administrator. Restart only what you changed:

Restart-Service RadioTEDUVotingRadio
Restart-Service RadioTEDU.JukeLocalMediaAgent
Restart-Service RadioTEDU.AIStreams
Restart-Service RadioTEDU.SharedAI

For YouTube, use Task Scheduler and run the appropriate active task: RadioTEDU YouTube Focus Stream V4 or RadioTEDU YouTube Classical Stream. The stream watchdog will also restore a missing supervisor automatically.

Guest-only JukeLocal test

  1. Open https://radiotedu.com/juke-local/controller/.
  2. Choose Hızlı başla with a non-personal test name. Do not choose member/admin login.
  3. Enter device code KOLEJ and connect.
  4. Confirm the account label says Misafir.
  5. Type a song or artist and press Enter to search.
  6. Select one approved result. Confirm “Şarkı kuyruğa eklendi!” and that Queue increases by one immediately.

A production guest test leaves one real queue entry. Use an identifiable, appropriate song.

Automatic recovery

  • The four application services start automatically before sign-in.
  • Windows restarts a failed service after 5, 15 and 30 seconds.
  • The service host relaunches a failed child process.
  • RadioTEDU-Autonomous-Watchdog checks semantic health every two minutes.
  • YouTube has task-level restart plus RadioTEDU Stream Watchdog.

If a component stays unhealthy after two watchdog cycles, record the time, component name and visible error. Never include a secret value.
