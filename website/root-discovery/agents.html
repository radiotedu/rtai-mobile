Connect with MCP

Use the Streamable HTTP endpoint. Public station and media information tools are available without an account or token.

https://radiotedu.com/mcp

The server uses MCP protocol version 2025-06-18. Send initialize, then discover tools, resources, and prompts with tools/list, resources/list, and prompts/list.

The server card summarizes the live server capabilities. Use tools/list for current input/output schemas and tool annotations: /.well-known/mcp/server-card.json.

Available tools

Read-only tools

  • get_station_status — status of the English or French AI station.
  • get_stations — active stations and metadata.
  • get_now_playing — current track and playback metadata.
  • get_broadcast_schedule — broadcast schedule for a station.
  • get_podcasts — public podcast series.
  • search_content — search public RadioTEDU content.
  • get_focus_presets — focus channels, ambient sounds, and study presets.
  • check_studio_availability — returns room metadata and aggregate availability flags only; it does not return occupant identities, contact details, or individual reservation records.

State-changing tool

book_studio_slot creates a reservation in RadioTEDU Hub ERP. It requires an authenticated ERP Bearer token, exact date and time, attendee count, purpose, explicit confirmation, and a reusable idempotency key. Account identity is obtained from the signed-in ERP profile; do not put names, email addresses, or phone numbers in tool arguments.

Call this tool only after the user explicitly requests a booking and confirms the complete proposed details. Do not infer permission from a general question about studios or availability. The tool response omits requester identity and contact details; do not include sensitive information in the purpose.

Sources and data handling

  • Use llms-ai.txt for the current consolidated content and MCP guide, llms.txt for the canonical content map, and ai.txt for a concise AI access summary.
  • Use openapi.json and the API catalog for documented REST API routes.
  • Schedules use Europe/Istanbul local time. Check timestamps for current station data and distinguish live playback from the published schedule.
  • Follow canonical RadioTEDU URLs returned by tools. Preserve Turkish names and do not infer missing dates, presenters, audience figures, or technical claims.
  • Studio availability contains room metadata and aggregate flags only. The MCP does not expose occupant identities, contact details, or individual reservation records.

These agent-discovery documents do not add or change existing RadioTEDU REST API routes.

Yapay zekâ ajanları için RadioTEDU

Güncel radyo ve podcast bilgilerine erişmek, güvenilir RadioTEDU kaynaklarını bulmak ve MCP araçlarının etkilerini ayırt etmek için Streamable HTTP uç noktasını kullanın:

https://radiotedu.com/mcp

Bağlantıdan sonra initialize; araç, kaynak ve istemleri keşfetmek için sırasıyla tools/list, resources/list ve prompts/list çağrılır. MCP protokol sürümü 2025-06-18. Sunucu kartı yetenekleri özetler; güncel girdi/çıktı şemaları ve araç işaretleri için tools/list çağırın.

Salt okunur araçlar

get_station_status, get_stations, get_now_playing, get_broadcast_schedule, get_podcasts, search_content, get_focus_presets ve check_studio_availability. Son araç yalnızca oda bilgisi ve toplu uygunluk işaretlerini verir; kişi adı, iletişim bilgisi veya tekil rezervasyon döndürmez.

Kayıt oluşturan araç

book_studio_slot, RadioTEDU Hub ERP'de rezervasyon oluşturur. Giriş yapmış ERP hesabı, açık kullanıcı onayı ve aynı işlem tekrarlarında kullanılacak idempotency anahtarı gerekir. Hesap kimliği giriş yapılmış profilden alınır; ad, e-posta veya telefon araç girdisi değildir ve yanıtında dönmez. Kullanıcı kesin tarih, saat ve katılımcı sayısını onaylamadan çağırmayın; amaç alanına hassas bilgi yazmayın.

Yayın saatleri Europe/Istanbul yerel saatidir. Canlı veride zaman damgasını kontrol edin; kanonik RadioTEDU bağlantılarını kaynak gösterin. Bu keşif belgeleri mevcut REST API rotalarını eklemez veya değiştirmez.
