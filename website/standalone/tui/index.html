02 / PLATFORM INSTALLATION MATRIX

Automated setup across Windows, macOS, and Linux.

Choose your preferred shell below. The installer checks Node.js, detects audio decoders (mpv or ffplay), and places the radiotedu binary globally on your system PATH.

WINDOWS 10 / 11 / SERVER

Direct npm Install (Recommended)

Clean and secure installation for Windows Command Prompt (CMD) and PowerShell. Standard package install without execution policy bypass or antivirus alerts.

CMD & PowerShell (Direct npm):
C:\>npm i -g https://radiotedu.com/tui/radiotedu-tui.tgz
PowerShell Script (Local File):
PS>irm https://radiotedu.com/install.ps1 -OutFile install.ps1; .\install.ps1
🛡️ Zero Defender Alerts: Native npm installation avoids dynamic in-memory execution and runs completely clean under Windows Defender.

🎵 Live Audio Streaming: Live streams require an audio decoder. Run: winget install Gyan.FFmpeg (or run radiotedu setup-audio).
MACOS & LINUX

Bash & Zsh One-Liner

POSIX installation script. Verifies your Node.js runtime and hardware audio decoders (mpv/ffplay), then downloads and configures the binary.

Terminal (bash / zsh):
$curl -sSL https://radiotedu.com/install.sh | bash
Launch Terminal Console:
$radiotedu
💡 Audio Engine: For hardware decoding, install mpv. macOS: brew install mpv · Ubuntu/Debian: sudo apt install mpv.
UNIVERSAL / NODE.JS

Direct npm Tarball & Login

Directly install the official production package hosted on radiotedu.com via npm across any operating system.

Global npm Package:
$npm i -g https://radiotedu.com/tui/radiotedu-tui.tgz
Device Pairing & Gold Sync:
$radiotedu login
⚡ Instant Login: Run radiotedu login and enter the 8-digit code from radiotedu.com/erp/device.

04 / KEYBINDINGS & CONTROLS

Full console control with single keystrokes.

Intuitive shortcuts designed to manage playback, community interaction, and telemetry without breaking your terminal flow.

Key Action Subsystem
Space Play / Pause (Instantly toggle live audio stream) Global Playback
m Mute / Unmute (Toggle sound without resetting stream buffer) Audio Engine
v Next-Song Voting (Open voting ballot and cast vote) Playout Interaction
c Studio Chat (Open live messaging and station announcements) Community Bridge
s Session Status (Display active Gold balance and stream stats) Account Telemetry
q Graceful Quit (Stop stream engine, save state and release port) Process Lifecycle

RadioTEDU uses ITU-R BS.1770-5 loudness and true-peak measurement with the EBU R128 broadcast reference. Streams are encoded by our internally compiled, non-distributed FFmpeg build using Fraunhofer FDK AAC: HE-AAC v2 for efficient low-bitrate delivery and AAC-LC at 192 kbit/s for full-quality listening.
